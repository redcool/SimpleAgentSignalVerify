# video-lip-sync

## 什么时候用

- 生成了一条演唱/口播视频，想先机器筛一遍再给人看；
- 用户说"口型不对"，需要区分是**偏了一点**还是**压根没跟**；
- 想确认"模型到底有没有用我们给的音频"。

## 命令

```bash
signalverify lip-offset --video take.mp4 --audio ref.wav --json out.json
```

## 输出怎么读（两个数就够）

| 字段 | 含义 |
|---|---|
| `best_lag_sec` | > 0 画面**滞后**；< 0 **提前** |
| `best_corr` | 嘴部运动与该音频的相关度 |

**判据（重要）**：

- `best_corr < 0.3` → 画面嘴部动作与这段音频关系很弱。常见原因是模型自己重唱了一版，
  或压根没做逐字口型。**此时不要去裁帧**，要先解决"音频是否真的驱动了口型"。
- `best_corr` 高 → **也不能证明音素级正确**。中文同口形异音很多，开合对不等于发音对。
  **必须人耳逐字听。**

## 局限

- Haar 级联在侧脸/遮挡/低头时丢帧，丢帧率见 `face_detected_frames`；
- 是启发式筛查，不是音素识别；
- 固定机位慢推镜头里 `lower_face_diff` 噪声大，优先看 `lower_face_edge`；
- **永远不能拿它当"口型通过"的标准。**
