# 工程纪律对照（SimpleMcpServer docsRules）

> 逐条对照《Agent工作纪律》与《Agent代码工程纪律》，写明本仓库怎么落地、
> 哪条还没做到。**没做到的要写出来，不许装。**

## 一、已落地

| 纪律 | 本仓库怎么做的 | 位置 |
|---|---|---|
| 模块化划分，每模块独立目录 | `core/` `audio/` `visual/` 三个模块目录 | `signalverify/` |
| 职责单一 / KISS | wavio 只读 WAV，lyric_timing 只做对齐，lip_offset 只做偏移 | 各模块 |
| 单一操作原则 | 每个方法只做一件事（`parse_lyrics` 只解析，`align_global` 只对齐） | 各模块 |
| 集中流程调度 | `cli.py` 是唯一编排入口，模块之间不互相调用 | `signalverify/cli.py` |
| 见名知意，禁止缩写 | `read_wav_mono` / `build_segments` / `lip_offset`；命令名由 `sv` 改为 `signalverify` | 全仓库 |
| 先读后写 | 修改前先读取目标文件 | 工作方式 |
| 最小修改 | 只改当前任务相关代码 | 工作方式 |
| 禁止静默失败 | 找不到 ffmpeg、解码 0 帧、无 ASR chunk 都直接抛错或返回显式字段 | `core/ffmpeg.py` 等 |
| 类型注解 | 公开函数带参数与返回值注解 | 各模块 |
| 禁止空 except | 只捕获具体异常或直接不捕获 | 各模块 |
| 注释用中文、讲为什么 | 关键处写"为什么这么做"，不复述代码 | 各模块 |
| 敏感信息 | 仓库内无任何 token / key / 密码 | 全仓库 |
| tmp 目录 | 项目侧临时文件全部在 `<工作区>/tmp/`，仓库内不产生 | 工作方式 |
| 测试绿灯才交付 | `python tests/run.py` 必须全绿 | `tests/` |

## 二、有偏离、已说明

| 纪律 | 偏离 | 处理 |
|---|---|---|
| 日志禁止 print | CLI 用 `print` 输出 JSON 报告 | JSON 是**产物**不是日志；诊断信息一律走 `logging`。已在 `cli.py` 区分 |
| 测试框架用 pytest | 本机无 pytest，改用零依赖 runner | `tests/run.py`，函数签名与 pytest 兼容，装了 pytest 可直接跑 |
| 删除移到 .trash | 仓库内尚未建 `.trash/` | 仓库是新建的，暂无删除操作；若日后要删，先建 `.trash/` |
