# 判据卡

开审前填完。填不出来的项，写"暂无"，并说明这一项交给谁。

```
交付物：
版本 / 日期：
审核者（谁、是否与创作者上下文隔离）：

合格线（用户在哪一步会卡住）：
  1.
  2.
  3.

红线（错了不能发）：
  1.
  2.

验收门槛（什么情况算过）：

量具（能用工具量的）：
  项目 | 工具/命令 | 阈值
  ---- | -------- | ----

人审边界（交给专业判断的）：
  项目 | 交给谁
```

## 填写要求

- **合格线必须能被观察到。**"体验不佳"不算；"第一次打开找不到开始按钮"算。
- **红线要能判定。**"不专业"不算；"数字没有口径"算。
- **量具一项，能填就填。**填了就要用；用了要写方法与参数，否则结论不可复核。
- **人审边界不许空着。**空着意味着审核员会替专家下判断，这是最危险的失败。
