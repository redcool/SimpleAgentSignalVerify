# 缺陷总表

第一段的唯一产物。**只分类、只计数、只指位置；不给改法，不写"更好版本"。**

## 分级

| 级别 | 定义 | 处理 |
|---|---|---|
| A | 事实错误、口径混用、逻辑断裂、违反红线 | 必改 |
| B | 目标用户会卡住、读不懂、理解错 | 必改 |
| C | 体例、格式、一致性 | 必改（成本低） |
| D | 结构、措辞、偏好 | 可选，写明理由 |

**"严重"只指 A、B、C。** D 级清零才放行，等于用偏好拖死进度。

## 表

```
类型 | 处数 | 位置 | 原句/原帧/原时间码 | 级别 | 说明
---- | ---- | ---- | ----------------- | ---- | ----
```

## 聚类要求

同一类病写一行，不要写成三十行。判别标准：**修法相同的就是同一类。**

例：

- 年份漂移 6 处（改年份统一查四处回填点）
- 对照表与正文不同步 4 处（表从正文校验）
- 指代悬空 3 处（"前者""后一份"没有对象）

聚类之后才进第二段。**没有聚类的总表，不许开始改。**

## 允许的结论

- "这一类没有问题。"
- "本轮只有 D 级。"
- "A 级 0 条。"

不允许为了显得有用而凑数。审核员的价值在命中，不在条数。
