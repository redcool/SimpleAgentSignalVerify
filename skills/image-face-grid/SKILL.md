# image-face-grid

## 什么时候用

- 要判断一张定妆照的"正气/邪气"，而不是凭感觉；
- 要横向比较几张候选（谁更方正）；
- 要检查硬光有没有伪造出"斜脸"。

## 命令

```bash
signalverify face-grid --image a.png b.png c.png --json grid.json
```

## 输出怎么读

| 字段 | 含义 |
|---|---|
| `eye_angle_deg` | 两瞳孔连线倾角（正值=右高左低） |
| `mouth_angle_deg` | 两嘴角连线倾角 |
| `parallel_gap_deg` | 两条线的夹角差，越接近 0 越平行 |
| `left_right_light_balance_norm` | 左右受光差。**它反映"光是否压暗一侧"，不是鼻梁歪斜** |
| `half_face_symmetry` | 左右半脸结构差，越小越对称 |
| `squareness_0_10` | 综合方正度 |

实测参考：同一批样张里，人工判"最方正"的得 8.2、"偏邪"的得 7.0，**顺序与人判一致**。

## 局限

- **测不出鼻梁是否真的歪**：没有关键点模型，中线与嘴角是估计值；
- Haar 对侧脸/低头会丢检测；
- 目测与测量在 2 度内不可分辨，别拿小数点论输赢；
- **只用于评审。** 实测把这套要求写进生成提示词，会把脸压成证件照（好看度从 7–8 掉到 5.5–6.5）。
